# 2026-03-31 — desktop-pet

## 01:10 — 데스크톱 펫 프로토타입 → 3D 캐릭터 + 사무실 + 테마 시스템 구축

OpenClaw vs Claude Code 비교 논의에서 시작 → "사내 AI 비서 + 귀여운 3D 캐릭터" 아이디어 → 하루 만에 프로토타입 완성.

**읽은 파일**: `main.js`, `pet.html`, `office.html`, `scripts/build_forest.py`, `scripts/build_platformer.py`, `scripts/build_restaurant.py`

**의사결정**:
- OpenClaw vs Claude Code → 보안(토큰 외부 유출) 이유로 **로컬 Claude Code + MCP** 방식 선택
- 멀티 윈도우 vs 단일 윈도우 → 줄서기/원근법 구현 위해 **단일 윈도우에 3마리 배치** (Three.js 씬 내 제어)
- 캐릭터 모델 → Three.js 공식 예제 **RobotExpressive.glb** (14개 애니메이션 내장, 453KB)
- 테마 에셋 → Blender CLI 스크립트로 자동 조립 → GLB export 파이프라인 구축

**챌린지**:
- Electron `focusable` 이슈: 데스크톱 펫이 다른 앱 작업을 방해 → `focusable: false` 기본, 단축키 시에만 `setFocusable(true)` → 채팅 끝나면 다시 `false`
- 3D 에셋 배치의 한계: 에셋 실제 크기를 모르고 좌표 찍으면 겹침/잘림 → Blender에서 측정(`measure_restaurant.py`) 후 정확한 배치
- 나무 텍스처 미적용: LowPolyTreePack의 vertex color가 GLTF export에 안 넘어감 → material node를 강제로 초록/갈색 지정하는 workaround
- 빼꼼 모션 본 조작 실패: 로봇 모델 bone을 직접 회전시키니 몸이 분리됨 → 본 좌표계가 로컬이라 값 추정 불가, charGroup 전체 기울이기로 타협

**코드 발견**:
- `BrowserWindow.setFocusable(false/true)` → 런타임에 포커스 가능 여부 토글 가능
- `globalShortcut.register('CommandOrControl+Shift+Space')` → Electron 글로벌 단축키
- Blender `--background --python script.py` → GUI 없이 CLI로 씬 조립/렌더/export
- Three.js `AnimationMixer` + bone 이름으로 `traverse` → 특정 본 접근 가능 (하지만 로컬 좌표계 주의)

**배운 것**:
- **Electron 데스크톱 펫 아키텍처**: 투명 윈도우(`transparent: true, alwaysOnTop: true`) + Three.js WebGL 렌더링 + IPC로 메인↔렌더러 통신
- **캐릭터 성격 시스템**: 애니메이션 시퀀스를 `[startAnim, holdAnim, duration]` 튜플로 정의 → one-shot → hold 전환으로 자연스러운 모션 체이닝
- **Blender CLI 파이프라인**: 에셋 팩에서 개별 조각 import → Python 스크립트로 배치 → GLB export → Three.js에서 로드. 프리뷰 렌더링으로 시각 확인 가능
- **Claude Code CLI subprocess 연동 가능성**: `claude --print "메시지"` 호출로 구독 과금 유지하면서 프로그래밍적 호출 가능. Agent SDK는 별도 API 키 필요(구독 불가)
